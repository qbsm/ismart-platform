# 2026-07-31 — Битые бакеты конфигуратора (sollers), ракурс/колорпикер (moskvich), название ДЦ в шапке (8 deployments)

## 1. Конфигуратор Атланта отдавал 404 (promo.sollers-avilon.ru)

**Симптом:** при клике по табам/базам конфигуратора Атланта картинки битые. Обход сайта этого не показал.

**Причина:** `assets/js/components/configurator.js` считал размерный бакет как `clientWidth × DPR` и при `need > 800` жёстко подставлял `/1280/`. Raw-исходники Атланта — 1200px, `build:images` не апскейлит, бакет 1280 не создан → 404. У Argo (raw 1280) и SF5 бакет есть, поэтому их конфигураторы целы.

**Почему обход не поймал:**
- В SSR-разметке `card-model.twig` есть ровно один config-URL (первая база, `/800/`) — он 200. Остальные 7 баз рождаются в JS по клику, их не видят ни curl-обход ссылок, ни PHP-200, ни `npm run verify`.
- Битая картинка появляется только *после* клика, первый экран всегда целый.
- Headless-скриншоты идут при DPR=1 → выбирается `/640/` → 200. Баг воспроизводится только при DPR ≥ 2.

**Фикс:** `card-model.twig` эмитит карту реально сгенерированных бакетов через штатный `image_variants()` (`<script class="js-configurator-sizes">`), SSR-src тоже берёт ключ из карты вместо хардкода `800`. JS выбирает наименьший бакет ≥ потребности **из карты**; при пустом манифесте откатывается на 640/800.

**Проверка:** puppeteer при DPR 2, прокликивание всех табов и баз, 404 собираются из network-лога. Прод до фикса — 10 кадров `naturalWidth=0`, 9×404. Локально после — все 200. SF5 берёт 1600, Argo 1280 (регрессии нет). Попутно карта чинит разнобой внутри SF5: у `l2h1` есть 1920, у `gruzpass` только 1600 — старая одно-бакетная логика этого не различала.

`deg360.js` проверен отдельно: бакеты 644/1280/raw существуют для всех моделей и цветов, чинить нечего. Компонент `configurator.js` есть только в sollers.

## 2. promo.moskvich-avilon.ru

- **Стартовый кадр 360 у M70/M90:** `startFrame` 32 → 33 + `npm run build:covers` сгенерил `33.cover.webp` для red и graphit. Без обложки первый кадр был бы битым — `deg360.twig` берёт `{start}.cover.webp`. Старые `32.cover.webp` остались на диске как мусор.
- **Колорпикер:** `.deg360__color-dot` имел `inset ... hsl(0 0% 100% / 20%)` — белая обводка на белой карточке (`.card-model { background: #fff }`), из-за чего свотч «Архангельский/Арктический белый» `#FBF8F8` был невидим. Заменено на `hsl(222deg 22% 12% / 32%)` (22% пробовали — слабо).

## 3. Название ДЦ в шапке — 8 deployments

`templates/components/dealer-list.twig`: `dealer.title` рендерится только при `dealers | length > 1`. Правило, а не разовая зачистка контента — появится второй ДЦ, название вернётся. Компонент подключён только в `sections/header.twig`, в футере/контактах его нет.

Результат: 7 репо с одним ДЦ (foton, havalavilon, havalpro, moskvich, sollers, wey, businesscar) — название убрано; `sales.avatr-avilon-moscow.ru` с двумя ДЦ — название осталось. У sollers остался ранее заведённый флаг `hideTitle: true` в шапке, теперь избыточный.

## Подводные камни

- **`auto_reload => false` в production** (`config/settings.php:143`): после `git pull` изменённые Twig-шаблоны не подхватываются, пока не снесён `cache/twig`. Для правок, живущих в Twig, чистка кэша обязательна наравне со сборкой.
- **`build:images` недетерминированно перекодирует AVIF**: один прогон дал 487 изменённых файлов, не связанных с задачей. Для обновления только манифеста прогон нужен, но диффы картинок надо откатывать.
- **`sales.businesscar-orel.ru` без git remote** — коммит остался локальным, на сервере хоста нет.
