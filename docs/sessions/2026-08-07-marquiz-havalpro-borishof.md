# 2026-08-07 — Квиз HAVAL PRO в Marquiz (задача трекера #233, БорисХоф)

## Задача

Из трекера (`ismart-task-tracker-bot`, задача 233, проект `chat.havalpro-borishof.ru`, от artem.didenko@borishof.ru): разработать посадочную страницу (квиз) в marquiz.ru для Haval PRO по ТЗ во вложении `1786084501276-Квиз_хавал.xlsx` (9 экранов: тизер, 5 вопросов, результат, форма, спасибо). Визуал — на усмотрение исполнителя.

## Что сделано

Квиз собран с нуля в кабинете Marquiz: `panel.marquiz.ru/quizzes/6a75997168aaa30019c1708a`, публичная ссылка `https://mrqz.me/6a75997168aaa30019c1708a`.

- **Дизайн** — своя тема под HAVAL PRO БорисХоф: фон `#1C1E22`, заголовки `#FFFFFF`, текст `#E6E8EA`, кнопки `#00CABF` с белым текстом (взято из `chat.havalpro-borishof.ru/static/css/main.min.css`, правило `.btn`).
- **Ассеты** — фото моделей H3/H5/H7/H9 из `chat.havalpro-borishof.ru/static/images/cars/*.webp` (конвертированы в PNG); обложка стартовой — от заказчика (`img.perxis.ru/.../d7361mgbeucc73ceeus0`, AVIF 3840×2160). фон стартовой у Marquiz — `.start-page__bg { background-size: cover; background-position: 0px 40% }`, то есть по горизонтали жёстко левый край, по вертикали точка 40%; настройки положения в UI нет. Из-за этого 16:9 обрезался справа, а кадр «в размер» 1792×1509 не закрывал колонку по высоте. В итоге заказчик прислал квадратный кадр той же сцены (`~/Downloads/original.jpg`, 3840×3840) — он подходит без дорисовок: уменьшен до 1792×1792 и поставлен как есть, при `position 0px 40%` линия машин попадает в видимую зону на любой высоте окна (проверено на 1568×733, 1440×1000, 1100×900). В слот «Изображение (мобильная версия)» положен исходный 16:9 (2400×1350); логотип — вектор `bodyshop.borishof.ru/project/assets/img/brand/brand-logo.svg` (чистое «БОРИСХОФ», fill #fff + #f00521), Marquiz принимает SVG. Растровое лого 600×48 давало размытие: рекомендуемая высота логотипа 37px, то есть на retina нужно ≥74px или вектор.
- **Экраны — все 9 из ТЗ, в порядке ТЗ.** Marquiz по умолчанию ставит форму перед результатами (вопросы → контакты → результаты → «Спасибо», причём «Спасибо» отключается, пока включён блок результатов). Чтобы получить порядок ТЗ (результат → форма → благодарность), результаты собраны **вопросами типа «Страница»** внутри блока вопросов, с ветвлением по ответу Q1 (H3/H5/H7/H9/«не определился»), а штатный блок «Результаты» удалён — после этого страница «Спасибо» разблокировалась. Итог: тизер → Q1–Q5 → страница-результат по модели (выгода до 300 000 ₽, «9 авто по спеццене — до 09.08», три плюшки, фото модели) → шаг «Что сделать в первую очередь?» (3 действия ТЗ: тест-драйв 🔥 / расчёт кредита / бронь) → форма (Имя + Телефон, Email удалён) → «Спасибо» с текстом ТЗ и кнопкой «Перейти на сайт БорисХоф» (borishof-havalpro.ru).
- **Фирменный шрифт** — Marquiz принимает свой шрифт (Regular + Bold, WOFF/WOFF2/TTF/OTF) на текущем тарифе: загружены `Haval-400.woff2` (Regular) и `Haval-500.woff2` (Bold) из `chat.havalpro-borishof.ru/static/fonts` — на их сайте Haval-500 объявлен как font-weight 700.
- **152-ФЗ** — «галочка согласия по умолчанию» выключена, согласие пользователь ставит явно.
- **Проверка** — квиз пройден целиком в проде, тестовая заявка (`test` / +7-911-111-11-11) показала корректный результат H7 и полный набор ответов; заявка удалена в корзину.

## Правки по итогам просмотра заказчиком

- Суммы набраны неразрывными пробелами, чтобы знак рубля не уезжал на другую строку. Важно: неразрывной делается только сама сумма («300 000 ₽», «2 500 000»), а пробелы вокруг тире и перед «до» остаются обычными — если сделать неразрывной всю строку, при нехватке ширины браузер рвёт её в произвольном месте и рубль всё равно отрывается. Побочный эффект: Marquiz подставляет заголовок в `<title>` без декодирования, и в имени вкладки видно `&nbsp;` — на самой странице всё корректно.
- Плюшки на страницах-результатах разбиты по строкам (без разделителя «·»), числа (300 000 ₽, 9 авто, 09.08, 5 лет) выделены жирным через тулбар редактора.
- Из вариантов вопроса про оплату убраны эмодзи; из подзаголовка стартовой убрано дублирование пометки о дилере (она есть в шапке).
- Логотип один на весь квиз, размер задаётся только пропорциями файла: в SVG увеличен viewBox по высоте (прозрачные поля) — так лого уменьшен примерно вдвое от исходного. Отдельный размер для стартовой и финальной страницы Marquiz не даёт; попытка положить лого картинкой в контент страницы «Спасибо» не годится — слот кропает изображение по бокам.

## Ограничения тарифа Marquiz

- **Своя политика конфиденциальности** — только на тарифе Плюс, используется дефолтная политика Marquiz.
- **Приглашения в проект** («Доступы в проект», совместная работа с заказчиком) — тоже Плюс.
- **Переадресация со страницы результата** — Плюс; кнопка на сайт реализована на странице «Спасибо», где ссылка доступна.
- Тариф аккаунта: 10 заявок / 30 дней.

## Передача заказчику

В карточке квиза (`···` → **«Перенести на другой аккаунт»**) вводится email пользователя Marquiz — квиз уходит вместе со всем содержимым; у заказчика должен быть аккаунт. Альтернатива — оставить квиз у нас и настроить пересылку заявок (Интеграции: почта/CRM/Telegram); совместный доступ через «Доступы в проект» требует Плюс.

## На согласование с заказчиком

- Контактный телефон дилера в футере квиза — очищен (в проекте `chat.havalpro-borishof.ru` только заглушка `+7 (899) 999-99-99`).
- Суммы выгод по моделям и количество авто по спеццене — в ТЗ приведены как примеры («9 авто до 09.08»); в квизе стоит нейтральное «Выгода до 300 000 ₽» и «Ограниченное количество автомобилей по спеццене».
- Три кнопки действий на экране результата (тест-драйв / расчёт кредита / бронь) в Marquiz не реализуются как три CTA — при необходимости добавляется шестым вопросом «Что сделать дальше?» перед формой.

## Гейты

Технические лимиты редактора Marquiz, найденные по ходу: заголовок стартовой — 100 символов, текст кнопки результата — 23 символа. Символ `₽` не вводится через синтетический ввод клавиатуры — вставлялся через `document.execCommand('insertText')` в tiptap-редактор.
