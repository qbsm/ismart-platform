# 2026-08-09 — Маска телефона: префикс якорем, формат шаблоном

Заявка с боевой формы пришла с номером `77999000002`, CallTouch отверг её с «номер телефона
не разрешен». Разбор показал дефект маски, а не ввода.

## Что было сломано

Прежняя реализация снимала код страны двумя независимыми проверками:

```js
if (d[0] === '7') d = d.slice(1);
if (d[0] === '8') d = d.slice(1);
```

При вставке номера в поле, где префикс `+7 (` уже проставлен, семёрок оказывается две —
снималась одна, и номер съезжал на разряд: `79990000022` превращалось в `7999000002`. Человек
этого не замечает: в поле видно правдоподобное `+7 (799) 900-00-02`.

## Что взято с боевой формы Т-Банка

Разобран их клиентский бандл формы дебетовой карты. Три приёма:

1. **Префикс снимается якорем как единый токен**, и только потом убираются нецифры:
   `e.replace(/^(\+\s*7|8|7)/, '').replace(/\D+/g, '')`. Наш вариант делал наоборот и потому
   мог сработать дважды.
2. **Формат задаётся шаблоном**, а не конкатенацией: таблица вида `RUS: "+7 999 999-99-99"`,
   где каждая девятка — слот под цифру, а подстановка — `mask.replace(/9/g, () => digits[i++])`.
   Добавить страну — строка в словаре, а не ветка в коде.
3. **Восьмёрка обрабатывается отдельной веткой** как российский транк, а не как ещё один
   префикс в общем списке.

## Чего у них нет и что пришлось добавить

Якорь работает, только когда префикс стоит в начале строки. При вставке поверх готового `+7 (`
код страны идёт следом — и там спотыкается сам оригинал: их поле в этом случае тоже даёт
`+7 799 900-00-02` (проверено подстановкой значения; их обработчик `paste` мой тест мог
обойти).

Поэтому к их схеме добавлена отбраковка по длине: лишние ведущие `7`/`8` снимаются, пока не
останется ровно столько цифр, сколько слотов в маске.

## Результат

Все формы ввода сходятся к одному номеру:

```
+79990000022         → +7 (999) 000-00-22    в запрос: 79990000022
+7 (79990000022      → +7 (999) 000-00-22    ← раньше съезжало
+7 (89990000022      → +7 (999) 000-00-22    ← раньше съезжало
89990000022          → +7 (999) 000-00-22
тел: 8-999-000-00-22 → +7 (999) 000-00-22
```

Из маски ушла зависимость от `inputmask`. Публичный API (`init/destroy/reset`) сохранён, правок
в `form-callback/index.js` не потребовалось.

## Побочное наблюдение

Их поле не принимает синтетический ввод: эмулированные события набора оставляют его пустым
(`+7 `). Реакция только на доверенные события — попутно защита от ботов, набивающих формы.
Нам это ломает автотесты через эмуляцию клавиатуры, поэтому свою маску такой делать не стали.
