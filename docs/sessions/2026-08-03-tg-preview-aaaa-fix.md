# 2026-08-03 — TG-превью: развязка. AAAA-хвост на REG.RU

Продолжение расследования «сниппеты в Telegram не отрабатывают на всех сайтах платформы»
(контрольные точки: lburo.ru работает, ya.ru работает; статический зонд показывал ноль
пакетов от фетчера к нашим origin'ам).

## Причина для kumho — протухшая AAAA-запись

В зоне kumho-tires.ru (ISPmanager REG.RU) рядом с A `31.31.196.72` висела AAAA
`2a00:f940:2:2:1:3:0:237` (apex и www) — IPv6-адрес хостинга, по которому сайт не
отвечает краулерам Telegram. Фетчер, имея выбор, уходил на IPv6, молча фейлился и
превью не строил; наши IPv4-проверки этого не видели.

Данил удалил обе AAAA в ISPmanager. Разъезд по зоне — минуты (serial 2026021869 → 71,
оба ns*.hosting.reg.ru чистые, публичные резолверы тоже). Проверка: сообщение с URL
новости через Bot API трекер-бота (свежий `?tg=0308` — мимо кэша превью) → в access-логе
прода REG.RU впервые появился классический краулер:

```
149.154.161.248 "GET /news/winter-all-season-collection-2026" 200 "TelegramBot (like TwitterBot)"
```

Сеть 149.154.x — собственные DC Telegram; раньше до сайтов платформы он не доходил вовсе.

## Selectel-сайты — уже здоровы

У promo.moskvich-avilon.ru (и остальных промо на sel) AAAA нет и не было — их превью
ломали nocache-заголовки сессии (починено в baseline 905db13 и раскатано). В nginx-логе
sel сегодня же зафиксирован RU-фетчер: `89.221.230.115 "GET /" 200
"TelegramBot/1.0 like Linux"` — origin достижим, превью строится.

## Хвосты

- **trazano-tires.ru, doublestar.ru, mirage-russia.ru** — та же AAAA
  `2a00:f940:2:2:1:3:0:237` в зонах (соседи kumho на vip237). Удалить в том же
  ISPmanager тем же способом.
- **beepitron.com** — AAAA нет; его проблема отдельная: IPv4 `31.31.196.254` в реестре
  блокировок (сосед по shared-хостингу) → тикет в REG.RU на смену IP.
- Старые «пустые» превью главных страниц закэшированы Telegram'ом — обновить через
  @WebpageBot после того, как понадобится (свежие URL строятся сразу).
- Нюанс TTL: первая попытка kumho (сразу после удаления AAAA) не построила карточку —
  резолверы TG ещё держали AAAA (TTL 3600). Вторая, через ~3 часа, прошла полный цикл:
  `GET /news/... 200` + `HEAD raw/cover-og.jpg 200` (185.70.52.14, «TelegramBot (like
  TwitterBot)») — карточка с картинкой построилась. Проверка moskvich подтверждена
  глазами: полная карточка (заголовок, описание, фото) в трекер-чате. Голый URL главной
  kumho краулер не перезабирал — кэш «превью нет» держится до сброса WebpageBot'ом.

Вывод «дело в сетевой блокировке» из прежних сессий скорректирован: для REG.RU-сайтов
дело было в AAAA-хвосте, для sel-сайтов — в no-store заголовках; сетевых блокировок
фетчера не осталось нигде, кроме beepitron (реестр).
