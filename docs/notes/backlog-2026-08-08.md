## Расхождения ядра с деплойментами

- [ ] **`DataExtension`** — baseline впереди: `normalizeManifestKey()` принимает
      абсолютные URL. В italycommunity была старая узкая версия, подтянута точечно;
      полноценный sync (вместе с `imageHas` и raw-source contract) — отдельной задачей.
- [ ] **`AssetExtension::getInlineCss`** — в italycommunity инлайнится весь main.css и
      переписываются относительные `url()`; в baseline инлайнится только critical.css без
      `url()`, поэтому переписывания там нет. Расхождение осознанное, но держать в виду:
      если в baseline появится инлайн main.css, нужна версия с учётом кавычек.
- [ ] **Индексация «готовых» webp** — baseline покрывает webp-исходники конвенцией
      `**/raw/*.webp` (ADR-0007), у italycommunity картинки событий лежат плоско, под это
      добавлен `--index-only`. Правильный путь — миграция картинок на `raw/`-раскладку.

      напрямую в CallTouch. Варианты: вебхук CallTouch → наш API (предпочтительно) либо
      периодическая выгрузка через API кабинета (нужен токен по каждому кабинету).
