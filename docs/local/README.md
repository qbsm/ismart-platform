# docs/local/ — локальная рабочая зона

Папка для **локальных заметок и ad-hoc скилов/скриптов** разработчика или конкретного deployment'а.

## Правила

- **Не коммитится.** Всё содержимое в `.gitignore`, кроме этого `README.md`. Заметки, черновики, временные скрипты остаются только на вашей машине / в этом клоне.
- **Не дистиллируется.** Это DEPLOYMENT-SPECIFIC зона (см. [`../architecture/distillation.md`](../architecture/distillation.md)) — `distill sync` её не трогает, drift не считается.
- **Не для канона.** Если заметка/скил оказались полезны всей платформе — перенесите в постоянное место: правило → `docs/conventions/`, архитектурное решение → `docs/architecture/` (ADR), переиспользуемый инструмент → `tools/`.

## Структура (создавайте по мере надобности)

```
docs/local/
  notes/     # черновые заметки, TODO, разборы, логи экспериментов
  skills/    # ad-hoc скилы/сниппеты/одноразовые скрипты под этот проект
  README.md  # этот файл (единственное, что коммитится)
```

> Подкаталоги `notes/` и `skills/` пусты в git (содержимое игнорируется) — заводите их локально командой `mkdir -p docs/local/{notes,skills}`.
