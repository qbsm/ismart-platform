# Proposal 0014: Маска телефона — код страны должен быть литералом, а не цифровым плейсхолдером

**Status:** Proposed
**Дата:** 2026-05-31
**Reference implementation:** `tank-avilon` — `assets/js/components/form-callback/constants.js`, `mask.js`
**Scope:** core — `assets/js/components/form-callback/` (компонент формы — общий для всех deployments)
**Related:** `docs/guides/form-callback-plan.md`, ADR-0007 (data-driven form validation, proposal 0007)

## Контекст

Поле телефона формы обратной связи использует Inputmask с паттерном (`constants.js`):

```js
export const PHONE_MASKS = {
  russia: '+9 (999) 999-99-99',
};
```

**Баг (воспроизведено на tank-avilon):** при автоподстановке браузера (а также при части ручных сценариев) поле принимает вид **`+9 (000) 000-00-0`** — неверная первая цифра (`9` вместо `7`) и номер **обрезан на один знак** (10 цифр вместо 11).

### Корневая причина

В Inputmask `9` — это **определение редактируемой цифры** (digit placeholder), а `7` — обычный **литерал**. В маске `+9 (999) 999-99-99` позиция кода страны задана как `9` → это пустой редактируемый слот, а не фиксированный `+7`. Итого:

- маска имеет **11** редактируемых цифровых слотов (`9` кода страны + 10), а российский локальный номер — 10 цифр;
- кастомная логика `mask.js` префиллит `RUSSIAN_COUNTRY_INFO.code` (`+7`) на `focus` и **срезает ведущую `7`** перед `inputmask.setValue(localDigits)` — рассчитывая на фиксированный `+7`. Но раз `+7` не литерал, цифры сдвигаются на один слот → неверная ведущая цифра и обрезание последнего знака;
- браузерная **автоподстановка** пишет «сырые» цифры прямо в 11 слотов (минуя normalize), что и даёт `+9 (000) 000-00-0`.

## Решение

Сделать код страны **литералом**:

```js
export const PHONE_MASKS = {
  russia: '+7 (999) 999-99-99',
};
```

Теперь `7` — фиксированный символ, остаётся ровно **10** редактируемых `9`-слотов = длина локального номера. Существующая логика `_applyMask` (срезание ведущей `7` → `setValue(10 цифр)`) становится корректной без сдвига. Префилл `+7` на focus согласуется с литералом.

## Структура файлов (baseline)

- `assets/js/components/form-callback/constants.js` — `PHONE_MASKS.russia: '+9 ...'` → `'+7 ...'`.
- `assets/js/components/form-callback/mask.js` — проверить/упростить: `_onFocus` префилл и `_applyMask` срез `7` (с литералом `+7` срез по-прежнему корректен; при желании упростить, т.к. setValue принимает 10 локальных цифр).
- (опц.) `_onAnimationStart`/`_onChange` — прогонять автоподставленное значение через `normalizePhone` + `_normalizeRussianNumber` ДО маски, чтобы `8XXXXXXXXXX`/`+7XXXXXXXXXX`/`9XXXXXXXXX` приводились к 10 локальным цифрам.

## Миграция

Тривиальная: правка строки маски. Прогнать сценарии (см. Acceptance). Для нерусских кодов (`COUNTRY_CODES`) — тот же принцип, если будут добавляться маски: код страны = литерал.

## Reference implementation

`tank-avilon` — фикс применён в `constants.js`. Проявление до фикса: автоподстановка → `+9 (000) 000-00-0`.

## Acceptance

- [ ] Маска показывает фиксированный `+7 (`, плейсхолдер `+7 (___) ___-__-__`.
- [ ] Автоподстановка телефона браузером → корректный `+7 (XXX) XXX-XX-XX`, без обрезания и без `+9`.
- [ ] Ввод `8XXXXXXXXXX`, `+7XXXXXXXXXX`, `9XXXXXXXXX`, вставка из буфера → нормализуются в `+7 (XXX) XXX-XX-XX`.
- [ ] Submit отправляет 11-значный номер (нормализованный) во все каналы.
- [ ] Distillation в остальные deployments (компонент общий).
- [ ] После принятия — миграция в ADR (next-номер).

## Rollback

`git revert` правки `constants.js` (возврат к `+9 ...`). Поведение возвращается к багу.
